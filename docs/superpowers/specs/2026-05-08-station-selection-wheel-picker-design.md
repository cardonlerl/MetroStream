# 站点选择页滚筒选择器设计

日期：2026-05-08

## 背景

当前站点选择页是搜索框加站点列表。它可用，但视觉上接近普通表单页，和「地铁意识流」的产品气质不够贴合。

本次优化改为 iOS 时间选择器式滚筒，不做圆形钟面。左列选择线路，右列选择当前线路下的站点。页面仍然服务真实坐地铁时的快速选择，同时让原型更有「地铁流动」的记忆点。

## 设计原则

- 不增加解释型说明文字。
- 不引入新的无关前端元素。
- 保留现有暖纸视觉系统。
- 优先真实操作效率，再处理氛围。
- 距离限制和发布流程不改变。

## 页面结构

页面仍由五块组成：

1. 顶部返回按钮。
2. 「出发站」「到达站」切换。
3. 已选路线短条，展示出发和到达。
4. 双列滚筒选择器。
5. 底部「进入车厢」按钮。

原搜索框和普通长列表不再作为主选择界面。

## 滚筒选择器

滚筒分两列：

- 左列：线路，例如 `1号线`、`2号线`、`7号线`。
- 右列：当前线路下的站点，例如 `静安寺`、`人民广场`、`南京东路`。

中间有一条轻量高亮带，表示当前选中的线路和站点。上下非选中项降低透明度，形成类似系统时间选择器的滚动层次。

交互行为：

- 滚动左列时，右列切换为该线路的站点。
- 滚动右列时，当前站点写入正在编辑的一端。
- 当前编辑对象由顶部 chip 决定：出发站或到达站。
- 选择出发站后可以自动切到到达站，延续当前流程的效率。
- 若当前线路不包含已选到达站或出发站，不强行清空另一端，只等待用户继续选择；路线可计算时再启用「进入车厢」。

## 出发站限制

出发站仍只能选择 2 公里内站点。

处理方式：

- 出发站模式下，线路列可显示包含附近站点的线路。
- 右侧站点列中，附近站点可选；不在范围内的站点不可写入出发站。
- 用户尝试选择不可用出发站时，沿用现有提示「你还没到站」。
- 到达站模式下可选择所有本地站点，不受距离限制。

## 数据流

`StationSelectionView` 仍然接收：

- `AppState`
- `LocationService`

新增或拆分的局部 UI 单元：

- `WheelStationSelector`：双列滚筒主体。
- `WheelColumn`：单列滚筒显示和选择。
- `StationPill`：复用当前已选短条样式。

状态建议：

- `query` 可移除或降级为后续备用，不作为主界面状态。
- `selectingDestination` 保留。
- 新增 `selectedLineID`，用于驱动右列站点。
- 选中站点后调用现有 `appState.selectStart(_:)` 或 `appState.selectDestination(_:)`。

## 视觉细节

- 背景继续使用 `SardineColors.paper`。
- 滚筒容器使用 `SardineColors.paperRaised` 和细边框。
- 中间选中带使用很浅的墨色透明层或暖灰层。
- 线路名可用小胶囊强调，站点名保持更大字号。
- 不使用暗色整屏滚轮。
- 不加入教程、标题解释、空洞说明文字。

## 验证标准

- 构建通过。
- 进入站点选择页后能看到双列滚筒。
- 左列切换线路会更新右列站点。
- 出发站模式下选择附近站点后写入出发站，并切到到达站。
- 出发站模式下尝试选择超出 2 公里的站点时出现「你还没到站」。
- 到达站模式下可选择所有本地站点。
- 出发和到达都选定且路线可计算后，「进入车厢」可用。
- 页面没有新增解释型说明文案。
